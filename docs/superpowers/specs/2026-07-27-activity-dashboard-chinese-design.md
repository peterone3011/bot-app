# 活动管理界面中文化设计

## 目标

将 Dashboard 中仅供管理员使用的活动管理界面完整中文化，同时保证 Discord 玩家侧内容继续使用英文。

## 中文化范围

- 活动管理导航、页面标题、面包屑和空状态。
- 活动列表中的状态、福利码数量和提交数量。
- 活动设置、福利码、提交记录三个页签。
- 配置字段标签、按钮、确认框、筛选项、表头、加载状态和错误提示。
- 前端活动校验错误及发布后字段锁定提示。
- 活动相关 API 返回给 Dashboard 的管理错误提示。
- 修复活动配置中频道选择器现有的中文乱码。

## 保持英文的内容

- Discord Embed 标题、正文、按钮文字和 Modal 标题。
- 玩家填写问题的标签、占位符和答案。
- 中奖、发完、结束及重试等 Discord ephemeral 回复。
- 新建活动时预置的全部玩家侧默认文案。
- Discord 频道名称及活动名称等管理员自行输入的数据。

管理界面中的字段名称使用中文，并在容易混淆的位置注明“该内容将对玩家展示”，但不自动翻译字段值。

## 实现约束

- 不修改数据库结构、Bot 行为、RPC 或活动数据。
- 不引入新的国际化框架；当前仅需要固定的中文管理员界面，直接维护中文界面文案更简单可靠。
- 状态值和提交结果仅在展示层映射为中文，API 与数据库枚举保持不变。
- CSV 数据内容保持原始值，避免改变已有导出接口的数据契约。

## 验证

- 更新组件测试，覆盖中文标题、按钮、状态、筛选和错误提示。
- 确认玩家侧默认英文文案未被翻译。
- 运行 Dashboard 全量 Vitest 和 Next.js 生产构建。
